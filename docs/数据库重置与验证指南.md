# 数据库初始化、演示数据替换与验证

更新：2026-10-24。要求 MySQL 8.0.16+，以支持 JSON_TABLE、窗口函数和 CHECK 约束。本项目的 32 张应用表之外可存在运行时辅助表。

## 替换现有演示数据，保留账号及权限

先停止后端写入并备份当前库。执行以下两个脚本，**不要对现有环境执行全量初始化脚本**：

```powershell
mysql --default-character-set=utf8mb4 -u root -p bike_assembly_mes -e "source sql/dev_seed_full.sql"
mysql --default-character-set=utf8mb4 -u root -p bike_assembly_mes -e "source sql/verify_database.sql"
```

`dev_seed_full.sql` 保留 `sys_user`、`sys_role`、`sys_menu`、`sys_role_menu`、`sys_config`、`sys_user_password_history`、`user_refresh_token`。角色、账号、密码、菜单权限、配置和会话不被重建。账号需包含启用的管理员、计划员、操作员、检验员和维修员；缺少必要角色账号时会在删除数据前报错。

脚本使用外键开启状态下按依赖顺序 DELETE，再批量插入，校验通过后 COMMIT；不使用 TRUNCATE，也不关闭外键检查。待检时间字段在事务前统一为可空。应用脚本若报错，应停止后续操作，并在同一连接 ROLLBACK；不要使用 mysql 的 `--force` 忽略错误。SQL 客户端连接断开时尚未提交的数据事务会回滚。字段结构调整由备份恢复，不属于数据事务回滚范围。

清理范围包括基础资料、工单、工序、质检、缺陷、设备维修保养、安灯、库存单据/流水/余额、安全记录及旧业务审计、幂等、MQ、ERP 技术记录。系统辅助表及上述七张身份配置表保持不变。完成后启动后端并刷新页面。

## 全新环境初始化

以下操作会删除并重建应用表，包括账号权限。仅用于新环境或明确需要全量重建的开发库：

```sql
CREATE DATABASE IF NOT EXISTS bike_assembly_mes
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

```powershell
mysql --default-character-set=utf8mb4 -u root -p bike_assembly_mes -e "source sql/init_database.sql"
mysql --default-character-set=utf8mb4 -u root -p bike_assembly_mes -e "source sql/dev_seed_full.sql"
mysql --default-character-set=utf8mb4 -u root -p bike_assembly_mes -e "source sql/verify_database.sql"
```

Docker Compose 与 CI 已按 `init_database.sql` → `dev_seed_full.sql` 顺序加载。初始化脚本只创建结构和系统种子数据，业务数据由第二步生成；已有 Docker 数据卷不会因文件改变自动重新初始化。

## 校验与自动化回归

41 项 SQL 检查覆盖：结构、BOM/路线引用、工序数量、工单/工序状态与数量、前序顺序、时间、初检复检关系、检验结果、缺陷来源、维修与设备状态、库存明细、流水链、余额和移库守恒，以及告警、安全与培训状态。

```powershell
node scripts/data/generate-demo-data.cjs
.\mvnw.cmd -pl bike-assembly-server -am "-Dtest=DemoSeedIntegrationTest" "-Dsurefire.failIfNoSpecifiedTests=false" test
```

回归测试默认启动 Testcontainers MySQL，不连接业务库。无 Docker 时可设置 `MES_REVIEW_MYSQL_URL=jdbc:mysql://localhost:3306/`、`MES_REVIEW_MYSQL_USER`、`MES_REVIEW_MYSQL_PASSWORD`，测试自动创建并删除随机命名的独立测试库。URL 必须指向服务器根路径，不能指定现有库。

测试还验证用户 ID、昵称与默认初始化不同的情况下仍能正确引用；重复清理会删除旧业务残留，并逐表比较七张身份配置表的内容摘要；人为破坏质检、设备、数量或库存流水会触发校验错误。
