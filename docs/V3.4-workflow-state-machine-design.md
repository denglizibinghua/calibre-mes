# V3.4 工序流转状态机设计文档

## 1. 概述

V3.4 实现了自行车组装 MES 系统的工序流转状态机完整闭环，包括工单生命周期管理、工序流转、质检返工闭环、MQ 事件通知、幂等和并发控制。

### 4.2 工序顺序解析优先级

1. 工艺路线 `steps_json` 中明确标注的 `seq`
2. `steps_json` 数组下标 + 1
3. 数据库当前工单最大 `step_seq` + 1
4. 安全默认值 1

容错处理：
- null/空字符串/非法 JSON → fallback
- 空数组 → fallback
- stepSeq 为字符串 → 尝试解析
- stepSeq ≤ 0 → 使用数组下标
- 工序不在 steps_json → fallback

## 5. 并发控制

- **乐观锁**：pro_work_order.version, pro_work_process.version, qms_inspection.version
- **原子 SQL 累加**：`UPDATE ... SET report_qty = report_qty + ? WHERE ... AND (report_qty + ?) <= plan_qty`
- **唯一索引**：request_id（幂等）、(work_order_id, step_seq)（防重）

## 6. 幂等策略

| 场景 | 幂等方式 |
|------|---------|
| 工单下达/暂停/恢复/取消/关闭 | 乐观锁 version + 状态前置检查 |
| 工序开工/报工/质检/返工 | 乐观锁 version + 状态前置检查 |
| 报工累计数量 | 原子 SQL 条件更新 |
| MQ 消息消费 | event_id 唯一索引去重（pro_message_consume_log） |
| 重复请求 | request_id 唯一索引 |

## 7. MQ 事件

### 7.1 事件类型

| 事件 | eventType | 触发方法 |
|------|-----------|---------|
| 工单已下达 | WORK_ORDER_RELEASED | releaseWorkOrder |
| 工单已暂停 | WORK_ORDER_PAUSED | pauseWorkOrder |

| 工单已关闭 | WORK_ORDER_CLOSED | closeWorkOrder |

| 工单已开始 | WORK_ORDER_IN_PROGRESS | onFirstProcessStarted |
| 工单已完工 | WORK_ORDER_COMPLETED | onLastProcessCompleted |
| 工序已开工 | PROCESS_STARTED | startProWorkProcess |
| 工序已报工 | PROCESS_REPORTED | reportComplete/reportWithInspection |
| 质检合格 | PROCESS_QC_PASS | qcPass |
| 质检不合格 | PROCESS_QC_FAIL | qcFail |
| 返工已开始 | PROCESS_REWORK_START | reworkStart |
| 返工已完成 | PROCESS_REWORK_COMPLETE | reworkComplete |
| 质检已确认 | INSPECTION_CONFIRMED | confirmInspection |

### 7.2 发送机制

使用 `@TransactionalEventListener(phase = AFTER_COMMIT)`：
- 数据库事务回滚 → 不发送消息
- 消息发送失败 → 不回滚已提交的业务事务
- 发送失败记录 WARN 日志，支持补偿

## 8. 异常码

| 异常 | 触发条件 |
|------|---------|
| StateMachineException("数据已被其他用户修改") | 乐观锁冲突 |
| StateMachineException("报工数量超出计划数量") | 超量报工 |
| StateMachineException("前序工序尚未完成") | 前序未完成开工 |
| StateMachineException("工单状态不允许生产操作") | 非可生产状态操作 |
| StateMachineException("当前状态不允许此操作") | 非法状态转换 |
