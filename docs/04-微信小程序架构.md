## 1. 概述

微信小程序是 MES 系统的**车间移动终端**，供一线工人和质检员在现场使用。它与 Web 管理端共享同一个 Spring Boot 后端，但使用独立的 `/app/**` 接口前缀和独立的 JWT 签名密钥。

### 1.1 与 Web 管理端的差异

| 维度 | Web 管理端 | 微信小程序 |
|------|-----------|-----------|
| 用户角色 | 计划员/管理员/质检员 | 车间工人/质检员 |
| 核心功能 | 管理配置 + 报表 + 全面操作 | 查看工单 + 工序报工 + 质检录入 |
| 登录方式 | 用户名+密码 | 微信一键登录 + 账号绑定 |
| 路由 | Vue Router SPA | uni-app pages.json |
| HTTP | Axios | uni.request |
| 导航 | 侧边栏菜单 | 底部浮动 TabBar |
| 离线能力 | 无 | 缓存管理(CacheManager) |
| 扫码 | 无 | uni.scanCode 条码扫描 |

## 3. 登录体系

### 3.1 双登录模式

```
┌──────────────────────────────────────┐
│          登录页 (login/index)         │
│                                      │
│  ┌──────────────────────────────┐    │
│  │  方式一：微信一键登录          │    │
│  │  [微信登录按钮]               │    │
│  │  → wx.login() → code        │    │
│  │  → POST /app/user/wx-login  │    │
│  │     ├─ 已绑定 → 直接登录     │    │
│  │     └─ 未绑定 → 跳转绑定页   │    │
│  └──────────────────────────────┘    │
│                                      │
│  ┌──────────────────────────────┐    │
│  │  方式二：用户名密码登录        │    │
│  │  [用户名] [密码] [登录]      │    │
│  │  → POST /app/user/login     │    │
│  └──────────────────────────────┘    │
└──────────────────────────────────────┘
```

### 3.2 微信登录完整流程

```
1. 用户点击"微信一键登录"
   │
   └─ uni.login({ provider: 'weixin' })
        └─ 获取临时 code

2. POST /app/user/wx-login  { code }
   │
   └─ 后端: code2Session(code) → openid
        │
        ├─ 已绑定(status=1):
        │     ├─ 生成 accessToken + refreshToken
        │     ├─ 加载权限 & 用户信息
        │     └─ 返回 { status:1, accessToken, refreshToken, userInfo }
        │         → 存入 uni.storage → 跳转首页
        │
        └─ 未绑定(status=2):
              ├─ 生成 tempToken (5分钟有效)
              └─ 返回 { status:2, tempToken, availableRoles }
                  → 存入 uni.storage → 跳转账号绑定页

3. 账号绑定页 (account-bind/index)
   │
   ├─ 绑定已有账号:
   │     ├─ 输入用户名 + 密码
   │     └─ POST /app/user/wx-bind
   │           Headers: Authorization: Bearer {tempToken}
   │           Body: { bindType:"existing", username, password }
   │           → 成功 → login() → 跳转首页
   │
   └─ 注册新账号:
         ├─ 输入昵称 + 选择角色
         └─ POST /app/user/wx-bind
               Body: { bindType:"new", nickname, roleId }
               → 成功 → login() → 跳转首页
```

## 4. HTTP 通信层

### 4.1 uni.request 封装

```typescript
// utils/request.ts

// 基础配置
const BASE_URL = VITE_API_BASE_URL  // 默认 http://127.0.0.1:8080

// Token 注入
headers: { token: accessToken }

// 响应处理
if (res.data.code === 1) return res.data.data  // 成功 → 解包

// 错误处理
- 401: 自动刷新 Token（请求队列防并发）
       失败 → 清除状态 → 跳转登录页
- 403: 刷新权限（30秒节流）
       安全检查 → 跳转安全拦截页
- 网络错误: Toast "网络连接失败"
```

### 4.2 缓存策略

```typescript
// utils/cache.ts — CacheManager

// 预定义缓存配置
CACHE_CONFIGS = {
  workOrders:       { ttl: 5 * 60_000, maxEntries: 100 },  // 5分钟
  workOrderDetail:  { ttl: 10 * 60_000 },                   // 10分钟
  referenceData:    { ttl: 30 * 60_000 },                   // 30分钟
  searchFilters:    { ttl: 24 * 60 * 60_000 },              // 24小时
}

// 缓存键格式: cache:{namespace}:{key}_u{userId}
// 自动按用户隔离
// TTL 过期自动失效
// LRU 驱逐策略控制容量
```

### 4.3 幂等键管理


```
// utils/network.ts

状态分类:
  online  (4G/5G/wifi/ethernet)   → 正常使用
  weak    (2G/3G)                  → 降级提示
  offline (none/unknown)           → 离线提示
```

## 7. 页面守卫模式

每个功能页面在 `onShow` 中执行三步守卫：

```typescript
onShow(() => {
  // 1. 认证守卫
  if (!userStore.isLoggedIn) {
    uni.reLaunch({ url: '/pages/login/index' })
    return
  }

  // 2. 权限守卫
  if (!hasPermission('app:work-order:view')) {
    uni.showToast({ title: '无访问权限', icon: 'none' })
    uni.navigateBack()
    return
  }

  // 3. 加载数据
  loadData()
})
```
