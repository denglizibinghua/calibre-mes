## 2. 状态机设计

### 2.1 工单状态机（7 状态）

```
                    ┌── cancel ──▶ CANCELLED("6") [终态]
                    │
CREATED("0") ──release──▶ RELEASED("4")
                              │
                    ┌─────────┘
                    ▼
            IN_PROGRESS("1")
               │         │
          pause│         │complete (所有工序完工)
               ▼         ▼
         PAUSED("5")  COMPLETED("2")
               │         │
          resume│    close│
               ▼         ▼
         IN_PROGRESS  CLOSED("3") [终态]
```

**状态码对照：**

| 代码 | 状态 | 中文 | 类型 |
|------|------|------|------|
| "0" | CREATED | 已创建 | 初始 |
| "4" | RELEASED | 已下达 | 活跃 |
| "1" | IN_PROGRESS | 生产中 | 活跃 |
| "2" | COMPLETED | 已完工 | 中间 |
| "3" | CLOSED | 已关闭 | 终态 |
| "5" | PAUSED | 已暂停 | 活跃 |
| "6" | CANCELLED | 已取消 | 终态 |

**合法转换：**
- CREATED → RELEASED, CANCELLED
- RELEASED → IN_PROGRESS, CANCELLED
- IN_PROGRESS → PAUSED, COMPLETED
- PAUSED → IN_PROGRESS
- COMPLETED → CLOSED

### 2.2 工序状态机（10 状态）

```
PENDING("0") ──前序完工──▶ READY("9")
                              │
                        ┌─────┼─────┐
                   skip │     │start│ skip
                        ▼     ▼     │
                  SKIPPED("7")      │
                  CANCELLED("8")    ▼
                            IN_PROGRESS("1")
                                 │
                   ┌─────────────┼─────────────┐
                   │ 无需质检     │ 需要质检      │
                   ▼             ▼              │
             COMPLETED("2") WAIT_INSPECTION("3")│
                             │        │         │
                       ┌─────┘        └─────┐   │
                       ▼                    ▼   │
                 QUALIFIED("4")      REJECTED("5")
                       │                    │
                       │           rework-start
                       │                    ▼
                       │              REWORK("6")
                       │                    │
                       │          rework-complete
                       │                    │
                       └────────────────────┘
                              强制重新质检
```

**状态码对照：**

| 代码 | 状态 | 中文 | 类型 |
|------|------|------|------|
| "0" | PENDING | 待开始 | 初始 |
| "9" | READY | 可开工 | 就绪 |
| "1" | IN_PROGRESS | 进行中 | 活跃 |
| "3" | WAIT_INSPECTION | 待检 | 等待 |
| "4" | QUALIFIED | 检验合格 | 中间 |
| "5" | REJECTED | 检验不合格 | 中间 |
| "6" | REWORK | 返工中 | 活跃 |
| "2" | COMPLETED | 已完成 | 终态 |
| "7" | SKIPPED | 已跳过 | 终态 |
| "8" | CANCELLED | 已取消 | 终态 |

**关键业务规则：**
1. **前序依赖**：只有前一道工序完成后，下一道才从 PENDING → READY
2. **质检闭环**：报工时根据 `process.needInspection` 决定是否创建检验单
3. **强制返工→质检**：`REWORK → rework-complete → WAIT_INSPECTION`，返工后必须重新质检，不允许直接完工
4. **工单联动**：所有工序完成后，自动将工单状态更新为 COMPLETED

### 2.3 检验单状态机（3 状态）

```
PENDING("0") ──录入结果──▶ ENTERED("1") ──确认──▶ CONFIRMED("2") [终态]
```

| 代码 | 状态 | 中文 |
|------|------|------|
| "0" | PENDING | 待检 |
| "1" | ENTERED | 已录入 |
| "2" | CONFIRMED | 已确认 |

### 2.4 QC结果枚举

| 代码 | 状态 | 中文 | 说明 |
|------|------|------|------|
| "0" | PENDING | 待检 | 初始 |
| "1" | PASS | 合格 | 全部检验项目通过 |
| "2" | FAIL | 不合格 | 任一检验项目不通过 |
| "3" | RECHECK | 待复检 | 返工后重新检验 |

## 3. 集中式状态机校验

### 3.1 StatusTransitionValidator

所有合法状态转换集中定义在 `StatusTransitionValidator` 的三个静态 `EnumMap` 中：

```java
// 工单转换规则
static {
    WORK_ORDER_TRANSITIONS.put(CREATED, Set.of(RELEASED, CANCELLED));
    WORK_ORDER_TRANSITIONS.put(RELEASED, Set.of(IN_PROGRESS, CANCELLED));
    WORK_ORDER_TRANSITIONS.put(IN_PROGRESS, Set.of(PAUSED, COMPLETED));
    WORK_ORDER_TRANSITIONS.put(PAUSED, Set.of(IN_PROGRESS));
    WORK_ORDER_TRANSITIONS.put(COMPLETED, Set.of(CLOSED));
    // CLOSED, CANCELLED 无出边（终态）
}

// 工序转换规则
static {
    PROCESS_TRANSITIONS.put(PENDING, Set.of(READY, SKIPPED, CANCELLED));
    PROCESS_TRANSITIONS.put(READY, Set.of(IN_PROGRESS, SKIPPED));
    PROCESS_TRANSITIONS.put(IN_PROGRESS, Set.of(WAIT_INSPECTION, COMPLETED));
    PROCESS_TRANSITIONS.put(WAIT_INSPECTION, Set.of(QUALIFIED, REJECTED));
    PROCESS_TRANSITIONS.put(QUALIFIED, Set.of(COMPLETED));
    PROCESS_TRANSITIONS.put(REJECTED, Set.of(REWORK));
    PROCESS_TRANSITIONS.put(REWORK, Set.of(WAIT_INSPECTION)); // 强制重新质检
    // COMPLETED, SKIPPED, CANCELLED 无出边（终态）
}

// 检验单转换规则
static {
    INSPECTION_TRANSITIONS.put(PENDING, Set.of(ENTERED));
    INSPECTION_TRANSITIONS.put(ENTERED, Set.of(CONFIRMED));
    // CONFIRMED 无出边（终态）
}
```

### 3.2 使用方式

```java
// 在 Service 层统一调用
if (!StatusTransitionValidator.canTransition(currentStatus, targetStatus)) {
    throw new StateMachineException(MessageConstant.STATUS_TRANSITION_DENIED);
    // → "当前状态不允许此操作"
}
```

## 4. DTO / VO 分层规范

### 4.1 分层原则

```
                 请求方向 →                  响应方向 →
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  前端    │───▶│   DTO    │───▶│  Entity  │───▶│   VO     │───▶ 前端
│ (JSON)   │    │ (校验)    │    │ (持久化)  │    │ (视图)    │    (JSON)
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 4.2 命名约定

| 类型 | 包路径 | 用途 | 注解 |
|------|--------|------|------|
| DTO | `com.bikeassembly.dto` | 入参接收 | Jakarta Validation (`@NotNull`, `@NotBlank`) |
| MessageDTO | `com.bikeassembly.dto.message` | MQ消息体 | `@Builder` |
| ReportDTO | `com.bikeassembly.dto.report` | 报表查询参数 | — |
| VO | `com.bikeassembly.vo` | 出参响应 | 无校验注解 |
| ReportVO | `com.bikeassembly.vo.report` | 报表结果 | 含JOIN字段 |
| ExcelVO | `com.bikeassembly.vo.report` | Excel导出 | EasyExcel `@ExcelProperty` |

### 4.3 校验分组

```java
// 仅在创建时校验
@NotNull(message = "产品不能为空", groups = OnCreate.class)
private Long itemId;

// 创建和更新都校验
@Size(max = 1, message = "状态长度不能超过1")
private String status;

// Controller 中指定分组
public Result<Void> create(@Validated(OnCreate.class) @RequestBody ProWorkOrderDTO dto) {}
public Result<Void> update(@Validated @RequestBody ProWorkOrderDTO dto) {}
```
